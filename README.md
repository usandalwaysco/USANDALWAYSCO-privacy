# USANDALWAYSCO-privacy

A minimal, static Privacy Policy page for the **Etsy Growth AI** tool used by
the Etsy shop **USANDALWAYSCO**, prepared for use as the required Privacy
Policy URL in a Pinterest Developer app (and other platform developer apps,
if needed later).

## Contents

- `index.html` — the full Privacy Policy page. Pure HTML/CSS, no external
  JavaScript, no analytics, no tracking. Responsive (readable on phone and
  desktop).
- `README.md` — this file.

## Before you publish

Open `index.html` and replace every occurrence of:

```
PLACEHOLDER_CONTACT_EMAIL
```

with a real contact email you actually control. Nothing else needs to
change unless you want to edit the policy text itself.

## How to publish with GitHub Pages

1. Create a new **public** GitHub repository named `USANDALWAYSCO-privacy`
   (or any name you prefer — just remember to update the expected URL below
   accordingly).
2. Push this folder's contents to that repository's `main` branch (you do
   this yourself — nothing here has been pushed for you).
3. In the repository, go to:
   **Settings → Pages → Build and deployment → Source: "Deploy from a
   branch" → Branch: `main`, folder: `/ (root)` → Save**
4. GitHub will publish the site within a minute or two.

## Expected URL

GitHub Pages URLs follow this pattern:

```
https://<GITHUB_USERNAME>.github.io/USANDALWAYSCO-privacy/
```

Replace `<GITHUB_USERNAME>` with your actual GitHub account username. This
was **not** filled in automatically because the real username is not known
here — do not guess it, confirm it from your own GitHub account.

Once published, that URL is what you paste into the Pinterest Developer
app's "Privacy Policy URL" field (and any other platform's developer app
that asks for one).
